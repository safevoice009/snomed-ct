## Verification procedure (all four must pass)

1. **MCA name search** — https://www.mca.gov.in → MCA Services → Check Company Name (exact + phonetic near-matches)
2. **IP India trademark search** — https://ipindia.gov.in → Public Search → Wordmark, Classes 9, 42, 44 (Vienna/phonetic too)
3. **Domain check** — registrar of choice: `.com`, `.in`, `.ai` (any two strongly preferred)
4. **Plain Google + GitHub search** — no active health-tech product with same/similar name in India

## Decision rules

- Any conflict in Class 9 or 42 → eliminate candidate immediately
- Only .ai available but not .com/.in → acceptable for dev-tool brand, weak for hospital sales
- Founder picks final name → freeze everywhere within 7 days (repo, site, docs, socials), then file trademark per checklist Stage 2
