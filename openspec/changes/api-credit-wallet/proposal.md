# Change Proposal: API Credit Wallet & Developer Checkout Hub

## Context
SICCE needs a direct developer monetization engine (the `ocr.run` / usage-based credit model) enabling visiting developers, clinics, and healthtech engineers to test, track API credits, and purchase top-up packs via UPI and cards with zero friction.

## Scope
1. **Developer API Credit Balance Bar**: Live visual credit meter in the Optical Workbench header.
2. **Instant Top-Up & Checkout Modal**: Pre-packaged API credit bundles (Starter ₹499, Pro ₹1,999, Scale ₹4,999).
3. **Backend Credit Balance & Package Endpoints**: Endpoints returning active balance and available packs.
4. **Automated Unit Testing**: Full Pytest suite validation for billing routes.
