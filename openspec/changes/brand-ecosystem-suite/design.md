- Component: `.mega-nav-wrapper` with responsive CSS dropdowns.
- Structure:
  - `Products`: Optical OCR, ABDM Gateway, Lens Mobile SDK, WhatsApp Bot, TPA Claims.
  - `Solutions`: Hospitals, E-Pharmacies, AYUSH, Diagnostic Labs, Insurance.
  - `Developers`: API Docs, Postman Hub, Python/Node/Go SDKs, Webhooks.
  - `Pricing`: Interactive ROI Simulator & Tier Cards.
